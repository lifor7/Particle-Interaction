# LIZI-3D

粒子辉光 · Three.js 星系环状粒子系统。

## 默认打开

**默认打开 `index.html`**（双形态：球形螺旋星云 + 无定形云，逐粒子概率着色 + 深邃星空配色）。

| 文件 | 说明 |
| --- | --- |
| `index.html` | **当前版本（默认）**：星云（球形内核 + 三环带）/ 无定形云 双形态切换，深邃星空配色 |
| `粒子辉光.html` | 旧版：球形内核 + 单环带，手势斥力推挤粒子 |

## 开发约定

**后续所有操作均作用于 `index.html`**。`粒子辉光.html` 为历史版本，仅作参考，不再修改。

**迭代方式：你问我答，逐轮贴近目标效果。** 讨论重点集中在**粒子效果**（形态、颜色、运动、辉光、密度等观感），而非代码实现细节。

**每次修改完成后自动在浏览器打开 `index.html`**，方便即时查看效果。
