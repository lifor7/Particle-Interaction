# Particle Interaction · 粒子交互

基于 Canvas 的交互式粒子动画引擎 —— 鼠标/触摸驱动的实时粒子系统，具备引力/斥力物理模拟、动态色彩渐变、发光光晕渲染与空间网格加速性能优化。

## 本地运行

```bash
# 方式一：直接打开（零依赖）
open index.html

# 方式二：静态服务器（推荐，避免 file:// 协议限制）
npx serve .
```

无需安装、无需构建、无需任何运行时依赖。仅需一个支持 Canvas 的现代浏览器。

## 交互操作

| 操作 | 桌面端 | 移动端 |
|------|--------|--------|
| 吸引粒子 | 移动鼠标 | 滑动手指 |
| 排斥粒子 | 按住鼠标左键 | 按住触摸 |
| 生成粒子 | 点击（不拖拽） | 触摸屏幕 |
| 切换引力/斥力 | 按 `Space` 或 `R` | — |

**粒子总数随屏幕尺寸自适应**：大屏约 200-350 个，小屏移动端自动减半，并设有全局上限防止卡顿。

## 视觉效果

- **三层粒子**（大/中/小按 15%/35%/50% 比例分配），各自独立的光晕半径与透明度
- **三层光晕绘制**（外层柔光 → 中层过渡 → 核心亮点），模拟径向渐变发光
- **动态色彩**：距离鼠标越近色相偏移越大，悬浮时色彩更鲜艳
- **连线渐变**：透明度 + 线宽双重距离插值，远距离连线更细更淡
- **柔和拖尾**：半透明画布覆盖实现残影，透明度可控避免画面糊团

## 性能优化

| 优化项 | 说明 |
|--------|------|
| 空间网格加速 | 将连线查找从 O(n²) 降为 O(n×k)，300+ 粒子场景比较次数减少 70-90% |
| 移动端粒子减半 | 屏幕宽度 < 768px 自动使用更大 divisor，降低 GPU 负载 |
| 标签页暂停 | `visibilitychange` 监听，后台标签页停止 `requestAnimationFrame` |
| 关闭抗锯齿 | `imageSmoothingEnabled = false`，粒子为简单几何形状无需平滑 |
| 透明通道关闭 | `getContext('2d', { alpha: false })`，减少合成开销 |
| 无效绘制过滤 | 连线透明度低于阈值直接跳过；透明粒子不参与网格构建 |

## 技术栈

- **Canvas 2D API** — 所有渲染基于原生 Canvas，无 WebGL 依赖
- **requestAnimationFrame** — 与显示器刷新率同步的动画循环
- **空间哈希网格** — 自定义 Spatial Hashing Grid 加速粒子对查找
- **devicePixelRatio** — 高 DPI 屏幕适配
- **Page Visibility API** — 标签页切换节能
- **Pointer Events 兼容** — 鼠标 + Touch 事件统一抽象

## 进阶特效

`particle-advanced.js` 提供四个可选拓展模块，按需复制到 `particle.js` 或独立引入：

1. **鼠标拖尾粒子** — 光标移动时生成跟随残影粒子
2. **流动渐变背景** — 缓慢旋转的全屏 HSL 渐变背景
3. **粒子碰撞物理** — 粒子间弹性碰撞与动量交换
4. **文字拆解粒子** — 将文字渲染为粒子阵列，可被打散重组

详见 `particle-advanced.js` 文件内注释说明。
